## Descripción del proyecto

Aplicación web que utiliza la API de OpenAI para realizar investigaciones académicas especializadas en el Instituto Tecnológico de Pachuca y en Ingeniería en Tecnologías de la Información y Comunicaciones.

El agente permite consultar información en Internet, analizar diversas fuentes, comparar resultados y generar reportes académicos estructurados mediante inteligencia artificial.

## Tecnologías utilizadas

- **Frontend:** HTML5, CSS3, JavaScript y Bootstrap.
- **Backend:** Python y Flask.
- **Inteligencia artificial:** OpenAI Responses API.
- **Búsqueda de información:** OpenAI Web Search.
- **Despliegue:** GitHub Pages y Vercel.
- **Almacenamiento del historial:** LocalStorage.
- **Exportación de documentos:** html2pdf.js.

## Funcionalidades principales

- Investigación académica especializada en TIC.
- Consultas relacionadas con el Instituto Tecnológico de Pachuca.
- Validación temática de las preguntas.
- Búsqueda y consulta de fuentes en Internet.
- Visualización del proceso de investigación en tiempo real.
- Generación de reportes académicos estructurados.
- Comparación de información y análisis de tendencias.
- Historial de investigaciones.
- Exportación de reportes en formato PDF.
- Interfaz moderna y adaptable a diferentes dispositivos.
- Protección de la API Key mediante variables de entorno en Vercel.

## Arquitectura

El proyecto utiliza una arquitectura separada en frontend y backend.

**GitHub Pages:** Aloja la interfaz web desarrollada con HTML, CSS y JavaScript.

**Vercel:** Ejecuta el backend Flask, administra las variables de entorno y procesa las solicitudes hacia OpenAI.

**OpenAI API:** Realiza las investigaciones, búsquedas web y generación de reportes académicos.

## Seguridad

La API Key de OpenAI se almacena mediante variables de entorno en Vercel, evitando exponerla directamente en el código JavaScript del frontend.
